# 桌面便签

找了一圈 Windows 便签软件，广告看了一堆，合自己用的却没找到。我实在受不了了，就在 AI 的辅助下手搓了一个。

桌面便签是一款 Windows 应用，可在桌面上同时放置多张便签。支持即时 Markdown 排版、事项提醒、登录自启动，以及通过云盘文件夹在多台 Windows 电脑间同步。

## 下载与安装

1. 在本仓库的 **Releases** 页面下载 `DesktopNotesSetup-V1.0.0.exe`。
2. 双击安装包，使用默认安装路径或选择其他目录。
3. 安装完成后选择打开，或从桌面快捷方式、开始菜单启动「桌面便签」。

升级时，先右键点击系统托盘里的便签图标，选择「退出」，然后安装到原目录。便签数据保存在当前 Windows 用户的 `%LocalAppData%\DesktopNotes\notes.xml` 中。

## 管理便签

- 点击工具栏的「新建便签」添加一张便签。拖动顶部空白区域移动窗口，拖动边框调整尺寸。
- 右上角从左到右是「置顶」「最小化」「关闭」。关闭会隐藏当前便签，删除整张便签请使用工具栏的「删除」。
- 双击桌面快捷方式可唤回有正文或提醒的便签。要查看所有便签（含空白便签），右键点击托盘图标并选择「显示所有便签」。
- 点击工具栏上的缩放百分比，或在正文区域按住 `Ctrl` 滚动鼠标滚轮，可以在 75% 到 250% 之间缩放正文。每张便签会记住自己的比例。
- 点击「格式」可以设置背景颜色、字体颜色或对选中文字应用格式。编辑内容会自动保存。

## Markdown 与快捷键

输入 `**加粗**`、`*斜体*`、`==高亮==` 或用反引号包住行内代码，结束标记输入后会直接显示排版效果。行首输入 `#`、`-` 或 `>` 再按空格，可创建标题、项目符号或引用。即时转换适用于键盘输入，粘贴整段 Markdown 后可用「格式」菜单调整。

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+U` | 下划线 |
| `Ctrl+Shift+H` | 高亮 |
| `Ctrl+Shift+C` | 行内代码 |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 放大正文 / 缩小正文 / 恢复 100% |

## 设置事项提醒

每张便签可添加多条一次性提醒。

- **手动添加**：点击「提醒」，填写日期、时间和事项说明，点击「添加」，最后点「保存」。
- **从文字识别**：在正文选中「明天下午三点半开会」或「下周三上午九点交报告」，点击「提醒建议」。核对预填时间和事项说明后，再添加并保存。识别到多个候选时，可以逐条切换。
- **修改或删除**：打开原便签的「提醒」列表并选中一条。修改时间或事项后点「修改提醒」，或点击「删除提醒」。两种操作都会保存并关闭提醒窗口。

提醒使用本机时区。到点后，Windows 会显示托盘通知，点击通知可打开对应便签。如果到点时程序已退出，下次启动会处理到期提醒。通知的实际显示取决于 Windows 通知设置。

## 开机自启动

在便签工具栏点击「设置」→「开机自启动」。开启后，登录 Windows 时会自动显示最近使用的有内容便签。如果希望登录后先收起窗口，可以勾选「自启动时最小化」。

## 跨设备同步

在每台电脑上安装便签和云盘客户端，再打开「设置」→「便签同步」→「选择同步文件夹」。每台电脑都应选择云盘中对应的同一个专用文件夹。

正文、格式和提醒会同步。窗口位置、尺寸、缩放和自启动选项按设备保存。可以在菜单中查看当前目录和同步状态、点击「立即同步」，或关闭同步。检测到同一便签在两端都已修改时，程序会保留另一份便签供核对。
